# Fleet Assistant — Backend

Реальный бэкенд, который ходит в Yandex Fleet API вашими ключами и определяет
проблемных водителей (неактивность, документы, баланс). Отдаёт данные чат-виджету.

## 1. Установка

```bash
cd backend
npm install
cp .env.example .env
```

## 2. Ключи Yandex Fleet API

В личном кабинете **fleet.yandex.kz** → Настройки → API (или обратитесь в
поддержку парка, если раздела не видно — доступ к API выдают не всем тарифам
автоматически). Получите:

- `X-Client-ID`
- `X-API-Key`
- `X-Park-ID` (это ID вашего парка)

Впишите их в `.env`:

```
YANDEX_CLIENT_ID=...
YANDEX_API_KEY=...
YANDEX_PARK_ID=...
```

Вместе с ключом Yandex обычно присылает ссылку на документацию именно вашего
контура API — **сверьте там `YANDEX_API_BASE`**, если хост будет отличаться
от значения по умолчанию в `.env.example`.

## 3. Запуск

```bash
npm start
```

Проверка: откройте `http://localhost:3001/api/health` → должно быть `{"ok":true}`.

## 4. Первая синхронизация

```bash
curl -X POST http://localhost:3001/api/drivers/refresh
```

Если получаете ошибку 401/403 — неверные ключи или у токена нет доступа к
`driver-profiles/list`. Если 200 — в ответе будет сводка по водителям.

## 5. Настройка проверки документов (важно!)

Сразу после первого успешного запроса откройте:

```
http://localhost:3001/api/debug/raw-driver
```

Это реальный JSON одного вашего водителя. Найдите там поля, отвечающие за
права/договор/техосмотр (названия отличаются по парку и региону — я не стал
их угадывать, чтобы не выдать неверную проверку за настоящую). Впишите
найденные пути в `lib/rules.config.js`, в массив `DOCUMENT_FIELD_PATHS`:

```js
DOCUMENT_FIELD_PATHS: [
  { label: "Водительское удостоверение", path: "driver_profile.driver_license.expiry_date", warnDaysBefore: 30 },
],
```

Пока этот массив пуст — дашборд честно показывает "документы не настроены",
а не молчаливо ничего не находит.

## 6. Эндпоинты для фронтенда (чат-виджета)

- `GET /api/drivers` — все водители + сводка
- `GET /api/drivers/problems` — только проблемные
- `POST /api/drivers/refresh` — принудительно обновить из Yandex
- `POST /api/chat` — `{ "question": "кто не выходил на линию 3 дня" }`

## 7. Опционально: свободные вопросы через Claude

Без `ANTHROPIC_API_KEY` чат работает на ключевых словах (документы /
неактивность / баланс / проблемы). Если добавить ключ Anthropic API в `.env`,
`/api/chat` начнёт понимать вопросы сформулированные свободно.

## 8. Чтобы чат-виджет (веб-артефакт) достучался до этого сервера

Виджет работает в браузере и должен обращаться к бэкенду по публичному
HTTPS-адресу — `localhost` из него недоступен. Варианты:
- задеплоить `backend/` на любой сервер (Render, Railway, свой VPS) — 5 минут;
- либо на время теста поднять туннель: `npx ngrok http 3001` и использовать
  выданный им https-адрес в виджете.
